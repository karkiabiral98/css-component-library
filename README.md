# CSSCraft

This is a small UI component library I built using only HTML and CSS — no JavaScript at all. I wanted to see how much I could actually pull off with pure CSS, and it turned out to be more than I expected.

## What's in it

- A navbar with a working hamburger menu on mobile (the toggle is done with a hidden checkbox, not JS)
- A few feature cards that tilt slightly when you hover over them
- Six different button styles — including one with a spinning loader, built with a CSS animation
- Colors are controlled from one place at the top of the CSS file, so changing the whole theme takes a few seconds

## Why I built this

I'm a BCA student learning frontend development, and most of the projects I found online use JavaScript for things like menus and interactions. I wanted to challenge myself and figure out how far CSS alone could go — turns out, pretty far.

## Tech used

Just HTML5 and CSS3. That's it. Font is Inter, from Google Fonts.

## How to run it

Clone this repo and open index.html in any browser. No installation, no build tools, nothing to set up.

git clone https://github.com/karkiabiral98/css-component-library.git
